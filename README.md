# My DevOps Project

A small Python application built to practice core Git version control skills — commits, branching, and collaboration via Pull Requests — as part of the DecodeLabs DevOps Internship (Project 2).

## What this project demonstrates
- Git repository initialization and structured commit history
- Feature branching isolated from `main`
- Pull Request workflow with review and merge
- Clean, professional commit messages

## Installation

```bash
git clone https://github.com/your-username/my-devops-project.git
cd my-devops-project
```

## Usage

```bash
python src/app.py
```

This prints a greeting and farewell message to the console.
